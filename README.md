## Building

**[Bedrock Python](https://bedrock-python.github.io)** — an open-source ecosystem of Python libraries for the infrastructure layer of backend services. Apache-2.0, published on PyPI, tested against real PostgreSQL, Redis and Kafka.

| Package | What it does |
|---|---|
| [servicewright](https://github.com/bedrock-python/servicewright) | Microservice runtime for async Python: multiple entrypoints under one Kubernetes lifecycle |
| [clientwright](https://github.com/bedrock-python/clientwright) | One retry / circuit-breaker / deadline / telemetry core behind the native `httpx`, `aiohttp`, `requests` and `urllib3` clients |
| [omni-box](https://github.com/bedrock-python/omni-box) | Transactional Outbox and Inbox for async Python services |
| [pg-partsmith](https://github.com/bedrock-python/pg-partsmith) | PostgreSQL partition lifecycle management — a plan you can read before it runs |
| [idempotency-kit](https://github.com/bedrock-python/idempotency-kit) | Idempotent request handling for async Python applications |
| [alembic-gauntlet](https://github.com/bedrock-python/alembic-gauntlet) | pytest toolkit that runs Alembic migrations forward, backward and against your models |

All packages, the layer map and the blog: [bedrock-python.github.io](https://bedrock-python.github.io) · [github.com/bedrock-python](https://github.com/bedrock-python)

## Open-source contributions

- **[centrifugal/centrifugo #1220](https://github.com/centrifugal/centrifugo/pull/1220)** (Go) — `CREATE TABLE IF NOT EXISTS … PARTITION OF` is not atomic: when several nodes start at once, the losing node got `42P07` and aborted the rest of the partition pass. Fixed in the PostgreSQL outbox partitioner; shipped in [v6.9.4](https://github.com/centrifugal/centrifugo/releases/tag/v6.9.4).
- **[pgmq/pgmq #585](https://github.com/pgmq/pgmq/pull/585)** (SQL) — partitioned queues silently overran `premake` and could not recover. Added the `premake` parameter, switched `msg_id` to `GENERATED BY DEFAULT`, exposed `default_partition_length` in `metrics()`, with migration, tests and docs; shipped in [v1.13.0](https://github.com/pgmq/pgmq/releases/tag/v1.13.0).
